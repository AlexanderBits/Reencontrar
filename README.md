# 🔍 Reencontrar: Achados e Perdidos Digital

O **Reencontrar** é uma plataforma colaborativa de utilidade pública desenvolvida para facilitar a devolução de objetos e documentos perdidos. O objetivo é criar uma rede de solidariedade digital onde quem perdeu possa localizar e quem achou possa cadastrar itens de forma rápida e geolocalizada.

## 🚀 Funcionalidades Principais
* **Mapa Interativo:** Visualização de itens achados e perdidos em tempo real utilizando Leaflet.
* **Cadastro de Itens:** Interface simples para descrição e upload de informações sobre o objeto.
* **Filtros por Categoria:** Busca facilitada por documentos, chaves, eletrônicos, pets e mais.
* **Design Neobrutalista:** Interface moderna, limpa e de alto contraste (Premium Neobrutalism UI).

## 🛠️ Tecnologias Utilizadas
* **Frontend:** React com TypeScript (`.tsx`) para uma interface robusta e performática.
* **Mapas:** Leaflet para geolocalização e visualização espacial.
* **Estilização:** Foco em Neobrutalismo para uma identidade visual única e marcante.
* **Metadados:** Gerenciamento estruturado de informações via `metadata.json`.

## 📂 Estrutura do Repositório
* `/src`: Lógica da aplicação e componentes da interface.
* `/docs`: Documentação técnica e manuais do MVP.
* `App.tsx`: Componente principal com a integração do mapa e fluxos de usuário.
* `index.tsx`: Ponto de entrada da aplicação.
